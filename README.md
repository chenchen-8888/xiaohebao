# 小荷包記帳本 👛

可愛、溫暖的淡黃色記帳網站，主要在手機上用，電腦也能開。

## 功能

- **記一筆**：金額、分類、日期、備註，還能選用現金、銀行或信用卡付
- **本月總覽**：本月支出、收入、結餘，以及資產總額（銀行存款 − 待繳卡費）
- **分類比例圖**：看錢都花去哪了，點一下分類看金額和百分比
- **明細列表**：依日期排列，可篩選支出／收入與分類，點一筆就能修改或刪除
- **銀行餘額**：每個帳戶各有多少錢
- **信用卡繳費提醒**：繳款日前 7 天首頁會提醒，繳完按「我繳好了」
- **備份**：匯出／匯入 JSON 備份檔

## 放上 GitHub Pages（免費網址）

1. 在 GitHub 建立一個新的 repository，例如 `xiaohebao`
2. 把 `index.html` 和 `README.md` 上傳上去（網頁上按 **Add file → Upload files** 就可以）
3. 進到 **Settings → Pages**
4. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
5. 等一兩分鐘，網址會是 `https://你的帳號.github.io/xiaohebao/`

在手機瀏覽器打開後，可以用「加入主畫面」，用起來就像一個 App。

## 資料存在哪裡？

所有紀錄都只存在**你自己這台裝置的瀏覽器**裡，不會上傳到任何伺服器，所以朋友用同一個網址，看到的也是他自己的帳。

要注意的是：

- 換手機、換瀏覽器，或清除瀏覽器資料，紀錄就不見了
- 請偶爾按頁面最下方的 **⬇️ 匯出備份**，把備份檔存好
- 換新手機時，用 **⬆️ 匯入備份** 就能把資料搬過去
- 手機和電腦的資料不會自動同步
